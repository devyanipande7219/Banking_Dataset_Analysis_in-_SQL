# 🏦 Banking Dataset SQL Project

## 📌 Overview

This project performs **Exploratory Data Analysis (EDA)** on a banking dataset using SQL. The objective is to understand customer behavior, financial activity, and relationships between different banking services such as accounts, transactions, loans, and credit cards.

The analysis is carried out on structured relational data to extract meaningful insights that can support business decisions.

---

## 📂 Dataset Description

The project is built using **five CSV-based tables**:

* **Customers** – Contains personal and demographic details
* **Accounts** – Includes account types and balances
* **Transactions** – Records transaction activity
* **Loans** – Stores loan amounts and related details
* **Credit Cards** – Contains credit limits and usage data

---

## 🛠️ Tools Used

* SQL (MySQL Workbench)
* CSV datasets
* Relational database concepts

---

## 🔍 Analysis Highlights

### 👥 Customer Insights

* Total number of customers analyzed
* Demographic breakdown (age, gender)
* Identification of active vs inactive customers

### 💳 Account Insights

* Distribution of account types (Savings, Checking, Investment)
* Balance analysis across customers
* Customers holding multiple accounts

### 💸 Transaction Insights

* Transaction volume and frequency
* Spending behavior patterns
* Identification of high-value transactions

### 🏦 Loan Insights

* Customers with the highest loan amounts
* Loan distribution across customer base
* Comparative analysis of loan values

### 💳 Credit Card Insights

* Total credit limits across customers
* Credit usage trends and patterns

## 📈 Key Insights

* Many customers maintain multiple types of accounts.
* Savings and Checking accounts are the most commonly used.
* Loan distribution is uneven, with a small number of customers holding higher loan amounts.
* Transaction activity shows consistent mid-range spending patterns.

3. Performed SQL-based exploratory data analysis
4. Generated insights using joins, aggregations, and filtering
5. Validated results through query outputs
